Creates a FunnelArea chart from encoded values and optional encoded labels. FunnelArea charts visualize stages in a process using area-encoded trapezoids, which can be used to show data in a part-to-whole representation similar to a piechart, wherein each item appears in a single stage. See also the "funnel" chart for a different approach to visualizing funnel data.
