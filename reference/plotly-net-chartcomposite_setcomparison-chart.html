Creates an UpSet plot visualizing the intersections between an arbitrary number of sets. An UpSet plot consists of an intersection matrix (which sets take part in each intersection), a bar chart of intersection sizes, a bar chart of the individual set sizes, and optionally additional per-intersection feature plots. Each input array is interpreted as a set: duplicate entries are ignored.

labels : 'a

Sets the labels of the compared sets, in the order they are drawn on the matrix' y-axis.

sets : 'b

Sets the members of each compared set, aligned with `labels`. Duplicate entries within a set are ignored.

?SetData : 'd

Sets per-set maps from a set member to an associated feature value, used together with `SetDataChartsTitle` to draw additional feature plots above each intersection.

?SetDataChartsTitle : 'e

Sets the charting function and title for each additional feature plot, aligned with `SetData`.

?MarkerSize : int

Sets the size of the markers in the intersection matrix. Defaults to 25.

?MainColor : Color

Sets the main color used for the bars and for sets present in an intersection. Defaults to dark blue.

?SecondaryColor : Color

Sets the color used for sets that are not present in an intersection. Defaults to light blue.

?DomainSet : float * float

Sets the x-axis domain of the set size bar chart. Defaults to (0., 0.2).

?DomainIntersection : float * float

Sets the x-axis domain of the intersection matrix and intersection size charts. Defaults to (0.3, 1.).

?TextFont : Font

Sets the font used for the axis titles. Defaults to Arial, size 20.

Creates a Venn diagram comparing two or three sets. The size of each circle is fixed; the diagram annotates each region (single sets and their intersections) with the number of members it contains. Each input array is interpreted as a set: duplicate entries are ignored.

set1 : 'a

Sets the members of the first set. Duplicate entries are ignored.

set2 : 'b

Sets the members of the second set. Duplicate entries are ignored.

?Set3 : 'c

Sets the label of the first set. Defaults to "Set 1".

?Label2 : string

?Label3 : string
